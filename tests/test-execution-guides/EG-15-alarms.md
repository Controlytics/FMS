# EG-15: Alarms -- Execution Guide

## Prerequisites
- **App URL**: http://3.108.185.106
- **API Base**: http://localhost:3000/api
- **SUPER_ADMIN Credentials**: admin / Admin@123
- **Alarms**: At least one alarm must exist (generated by rule chain processing or manually inserted)
- **Permissions**: ASSET_VIEW for reading, ALARM_MANAGE for acknowledge/clear

## Setup

```bash
TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Admin@123"}' | jq -r '.token')

# Check existing alarms
sudo -u postgres psql digilog_db -c "SELECT id, entity_id, alarm_type, severity, status FROM alarms ORDER BY created_at DESC LIMIT 10;"
```

### Test: TC-15-P10 -- Acknowledge Alarm

**API (curl):**
```bash
# Find an ACTIVE alarm
ALARM_ID=$(curl -s -X GET "http://localhost:3000/api/alarms?status=ACTIVE&limit=1" \
  -H "Authorization: Bearer $TOKEN" | jq -r '.data[0].id')

echo "Acknowledging alarm: $ALARM_ID"

curl -s -X POST "http://localhost:3000/api/alarms/$ALARM_ID/acknowledge" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "signerFullName": "Test Administrator",
    "meaning": "Alarm reviewed and acknowledged during QA testing",
    "remarks": "Temperature spike was within acceptable tolerance"
  }' | jq .
```

**Expected Result:**
```json
{
  "alarm": {
    "id": "uuid",
    "status": "ACKNOWLEDGED",
    "acknowledged": true,
    "acknowledgedBy": "admin",
    "acknowledgedAt": "2026-03-05T...",
    "ackRemarks": "Temperature spike was within acceptable tolerance",
    "ackSignatureId": "signature-uuid"
  },
  "signature": {
    "id": "signature-uuid",
    "recordType": "alarm",
    "signerUserId": "admin-user-id",
    "signerFullName": "Test Administrator",
    "meaning": "Alarm reviewed and acknowledged during QA testing",
    "recordHash": "sha256-hex",
    "signatureHash": "sha256-hex"
  }
}
```

**DB Verification:**
```bash
sudo -u postgres psql digilog_db -c "SELECT id, status, acknowledged, acknowledged_by FROM alarms WHERE id = '$ALARM_ID';"
sudo -u postgres psql digilog_db -c "SELECT * FROM electronic_signatures WHERE record_id = '$ALARM_ID';"
```

**Pass/Fail:**
- [ ] Alarm status changed to ACKNOWLEDGED
- [ ] acknowledged = true
- [ ] acknowledgedBy matches username
- [ ] Electronic signature created
- [ ] signatureHash is valid SHA-256
